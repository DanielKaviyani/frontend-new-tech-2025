# Tech24 - Jotai

## 🎯 Learning Objectives
Master Jotai's atomic state management with granular reactivity, minimal re-renders, and modern React patterns.

## 📋 Prerequisites
- React fundamentals
- JavaScript/TypeScript
- Understanding of atoms concept
- Hooks experience

## 📚 Curriculum

### Week 1: Jotai Fundamentals
- [ ] Atomic state management philosophy
- [ ] Basic atom creation and usage
- [ ] Read-only and write-only atoms
- [ ] Component subscription patterns
- [ ] **Project**: Atomic counter app

### Week 2: Advanced Atom Patterns
- [ ] Derived atoms and dependencies
- [ ] Async atoms and suspenses
- [ ] Writable atoms with actions
- [ ] Atom families and dynamic atoms
- [ ] **Project**: Complex atom relationships

### Week 3: Utilities and Integration
- [ ] AtomWithStorage for persistence
- [ ] AtomWithQuery for data fetching
- [ ] AtomWithObservable for RxJS
- [ ] Custom atom utilities
- [ ] **Project**: Full-featured application

### Week 4: Performance & Scale
- [ ] Performance optimization patterns
- [ ] Large-scale atom architecture
- [ ] Debugging and DevTools
- [ ] Testing atomic state
- [ ] **Final Project**: Production system
