# Tech13 - Sass/SCSS Advanced Features

## 🎯 Learning Objectives
Master Sass/SCSS advanced features including mixins, functions, control directives, and modern preprocessing workflows.

## 📋 Prerequisites
- CSS fundamentals
- Basic Sass/SCSS knowledge
- Understanding of variables and nesting
- Command line basics

## 📚 Curriculum

### Week 1: Advanced Variables and Data Types
- [ ] Maps and complex data structures
- [ ] Variable scope and !global
- [ ] Default variables and configuration
- [ ] String interpolation advanced
- [ ] **Project**: Configuration system

### Week 2: Mixins and Functions
- [ ] Advanced mixin patterns
- [ ] Content blocks and @content
- [ ] Built-in functions deep dive
- [ ] Custom function creation
- [ ] **Project**: Utility function library

### Week 3: Control Directives
- [ ] @if, @else if, @else
- [ ] @for loops with variables
- [ ] @each with maps and lists
- [ ] @while loops
- [ ] **Project**: Dynamic grid system

### Week 4: Modern Workflows
- [ ] @use and @forward modules
- [ ] @import vs @use migration
- [ ] Custom importers
- [ ] Performance optimization
- [ ] **Final Project**: Complete framework
