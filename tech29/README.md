# Tech29 - Jest & Testing Library

## 🎯 Learning Objectives
Master Jest for unit and integration testing with React Testing Library for component testing, focusing on user-centric testing approaches.

## 📋 Prerequisites
- JavaScript/TypeScript fundamentals
- React component knowledge
- Testing concepts and terminology
- Node.js environment familiarity

## 🛠 Tools & Setup
```bash
# Install Jest and Testing Library
npm install -D jest @testing-library/react @testing-library/jest-dom
# For TypeScript support
npm install -D @types/jest ts-jest
# For custom hooks testing
npm install -D @testing-library/react-hooks
```
