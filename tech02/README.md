# Tech02 - Vue.js 3 with Composition API

## 🎯 Learning Objectives
Master Vue.js 3's Composition API, reactivity system, and modern development patterns for building maintainable applications.

## 📋 Prerequisites
- JavaScript fundamentals (ES6+)
- Basic HTML & CSS
- Understanding of component-based architecture

## 📚 Curriculum

### Week 1: Vue 3 Fundamentals
- [ ] Vue 3 architecture and improvements
- [ ] Composition API vs Options API
- [ ] Reactivity system (ref, reactive, computed)
- [ ] Template syntax and directives
- [ ] **Project**: Personal portfolio with Vue 3

### Week 2: Composition API Deep Dive
- [ ] setup() function and script setup
- [ ] Composables and reusable logic
- [ ] Lifecycle hooks in Composition API
- [ ] Watch and watchEffect
- [ ] **Project**: Task management app

### Week 3: Advanced Vue 3 Features
- [ ] Teleport and Fragments
- [ ] Custom directives
- [ ] Plugin development
- [ ] Provide/Inject pattern
- [ ] **Project**: Component library

### Week 4: Vue Ecosystem
- [ ] Vue Router 4
- [ ] Pinia for state management
- [ ] Testing with Vue Test Utils
- [ ] Performance optimization
- [ ] **Final Project**: SPA with routing and state management

## 🛠 Tools & Setup
```bash
# Create Vue 3 project
npm create vue@latest my-vue-app
# or with Vite
npm create vue@latest my-vue-app -- --template typescript
```
