# Tech03 - Svelte 5 & SvelteKit

## 🎯 Learning Objectives
Master Svelte 5's compiler-based approach, runes system, and SvelteKit's full-stack capabilities for building ultra-fast web applications.

## 📋 Prerequisites
- JavaScript fundamentals (ES6+)
- HTML & CSS basics
- Understanding of component concepts

## 📚 Curriculum

### Week 1: Svelte 5 Fundamentals
- [ ] Svelte compilation philosophy
- [ ] Svelte 5 runes system ($state, $derived, $effect)
- [ ] Component structure and syntax
- [ ] Reactivity without virtual DOM
- [ ] **Project**: Counter app with runes

### Week 2: Advanced Svelte Features
- [ ] Slots and composition patterns
- [ ] Stores and state management
- [ ] Transitions and animations
- [ ] Custom actions and transitions
- [ ] **Project**: Interactive photo gallery

### Week 3: SvelteKit Introduction
- [ ] File-based routing system
- [ ] Load functions and data fetching
- [ ] Form actions and mutations
- [ ] API routes and endpoints
- [ ] **Project**: Blog with CMS integration

### Week 4: SvelteKit Advanced
- [ ] Advanced routing patterns
- [ ] Server-side rendering (SSR)
- [ ] Static site generation (SSG)
- [ ] Deployment strategies
- [ ] **Final Project**: Full-stack e-commerce site

## 🛠 Tools & Setup
```bash
# Create SvelteKit project
npm create svelte@latest my-svelte-app
cd my-svelte-app
npm install
npm run dev
```
