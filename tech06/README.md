# Tech06 - Next.js 15

## 🎯 Learning Objectives
Master Next.js 15's App Router, Server Components, and full-stack capabilities for production applications.

## 📋 Prerequisites
- React 18+ knowledge
- TypeScript basics
- Understanding of web fundamentals

## 📚 Curriculum

### Week 1: App Router Fundamentals
- [ ] App Router vs Pages Router
- [ ] File-based routing system
- [ ] Layouts and nested layouts
- [ ] Loading and error states
- [ ] **Project**: Multi-page marketing site

### Week 2: Server Components & Data
- [ ] Server Components patterns
- [ ] Data fetching strategies
- [ ] Caching and revalidation
- [ ] Streaming and suspense
- [ ] **Project**: Blog with CMS

### Week 3: Full-Stack Features
- [ ] API routes and middleware
- [ ] Authentication patterns
- [ ] Database integration
- [ ] Form handling and mutations
- [ ] **Project**: Full-stack CRUD app

### Week 4: Advanced Patterns
- [ ] ISR and on-demand revalidation
- [ ] Edge runtime
- [ ] Performance optimization
- [ ] Deployment strategies
- [ ] **Final Project**: SaaS application

## 🛠 Tools & Setup
```bash
# Create Next.js project
npx create-next-app@latest my-next-app --typescript --tailwind --app
cd my-next-app
npm run dev
```
