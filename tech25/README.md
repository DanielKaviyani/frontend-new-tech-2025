# Tech25 - MobX

## 🎯 Learning Objectives
Master MobX's reactive state management with observable patterns, computed values, and transparent functional reactive programming (TFRP).

## 📋 Prerequisites
- JavaScript/TypeScript knowledge
- Understanding of reactive programming
- Object-oriented concepts
- Decorators knowledge (helpful)

## 📚 Curriculum

### Week 1: MobX Fundamentals
- [ ] Observable state and actions
- [ ] Computed values and reactions
- [ ] MobX vs Redux philosophy
- [ ] Basic store patterns
- [ ] **Project**: Simple observable app

### Week 2: Advanced Reactivity
- [ ] Reactions and autorun
- [ ] When and reaction utilities
- [ ] Async actions and flows
- [ ] Custom observables
- [ ] **Project**: Complex reactive system

### Week 3: React Integration
- [ ] mobx-react-lite integration
- [ ] Observer pattern implementation
- [ ] Local component state
- [ ] Performance optimization
- [ ] **Project**: React-MobX application

### Week 4: Enterprise Patterns
- [ ] Modular store architecture
- [ ] Dependency injection
- [ ] Testing observables
- [ ] Migration strategies
- [ ] **Final Project**: Enterprise application

## 🛠 Tools & Setup
```bash
# Install MobX
npm install mobx
# For React integration
npm install mobx-react-lite
# For decorators (optional)
npm install -D @babel/plugin-proposal-decorators
```
