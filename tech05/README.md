# Tech05 - Angular 18+ (Standalone Components)

## 🎯 Learning Objectives
Master Angular's standalone component architecture, signals, and modern development patterns for enterprise-scale applications.

## 📋 Prerequisites
- Strong TypeScript knowledge
- Object-oriented programming concepts
- RxJS fundamentals

## 📚 Curriculum

### Week 1: Angular Modern Architecture
- [ ] Standalone components (no NgModules)
- [ ] Angular signals reactivity
- [ ] Dependency injection modernized
- [ ] Component composition patterns
- [ ] **Project**: Component library

### Week 2: Advanced Features
- [ ] Reactive forms with signals
- [ ] HTTP client with interceptors
- [ ] Route guards and resolvers
- [ ] Lazy loading strategies
- [ ] **Project**: Admin dashboard

### Week 3: State Management
- [ ] NgRx signals integration
- [ ] Component store patterns
- [ ] Effects and side effects
- [ ] Entity management
- [ ] **Project**: Complex state management app

### Week 4: Enterprise Patterns
- [ ] Micro-frontend architecture
- [ ] Angular elements (web components)
- [ ] Performance optimization
- [ ] Testing strategies
- [ ] **Final Project**: Enterprise application

## 🛠 Tools & Setup
```bash
# Create Angular project with standalone
ng new my-angular-app --standalone --routing --style=scss
cd my-angular-app
ng serve
```
