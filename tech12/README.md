# Tech12 - Styled Components & CSS-in-JS

## 🎯 Learning Objectives
Master CSS-in-JS solutions including Styled Components, Emotion, and modern styling approaches for component-driven development.

## 📋 Prerequisites
- React fundamentals
- CSS fundamentals
- JavaScript ES6+
- Component-based thinking

## 📚 Curriculum

### Week 1: CSS-in-JS Fundamentals
- [ ] CSS-in-JS philosophy and benefits
- [ ] Styled Components basics
- [ ] Template literals and tagged templates
- [ ] Props-based styling
- [ ] **Project**: Styled component library

### Week 2: Advanced Styling Patterns
- [ ] Dynamic styling with props
- [ ] Theme providers and context
- [ ] Global styles and reset
- [ ] CSS animations with styled-components
- [ ] **Project**: Themed application

### Week 3: Alternative Solutions
- [ ] Emotion vs Styled Components
- [ ] Stitches utility-first CSS-in-JS
- [ ] Vanilla Extract zero-runtime
- [ ] Linaria build-time CSS-in-JS
- [ ] **Project**: Compare solutions

### Week 4: Performance & Best Practices
- [ ] Server-side rendering with CSS-in-JS
- [ ] Bundle size optimization
- [ ] TypeScript integration
- [ ] Migration strategies
- [ ] **Final Project**: Production application

## 🛠 Tools & Setup
```bash
# Install Styled Components
npm install styled-components
# or Emotion
npm install @emotion/react @emotion/styled
```
